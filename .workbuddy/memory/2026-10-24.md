## wx-backend JDK 25 + Spring Boot 4.1 大版本升级（BUILD SUCCESS）

- **升级前**: Spring Boot 2.2.6.RELEASE / Java 8
- **升级后**: Spring Boot 4.1.2（Spring Framework 7 / Security 7 / Thymeleaf 3.1.5 / Tomcat 11）+ JDK 25（D:/Tools/jdk-25.0.2，Maven 3.9.9）
- **pom.xml 变更**:
  - starter-web → spring-boot-starter-webmvc（Boot 4 模块化改名）
  - 移除未使用的 spring-boot-starter-data-jpa（全项目无 @Entity/JpaRepository）
  - mysql-connector-java → com.mysql:mysql-connector-j（parent 管理版本）
  - mybatis-spring-boot-starter 2.1.0 → 4.1.0（Boot 4 适配版）
  - fastjson 1.2.68 → fastjson2 2.0.66 + fastjson2-extension-spring6 2.0.66
  - druid 1.2.28、guava 33.7.2-jre、commons-lang3 3.21.0、commons-collections4 4.6.0、hutool 5.8.48、JustAuth 1.16.7、logstash-logback-encoder 9.0、thymeleaf-layout-dialect 4.0.1
  - maven-compiler-plugin 增加 `<proc>full</proc>` + annotationProcessorPaths(lombok)：JDK 23+ 默认禁用隐式注解处理，Lombok 必须显式声明，否则 setter/log 全部编译失败
  - aliyun 仓库 http → https://maven.aliyun.com/repository/public；mvnw wrapper 3.6.3 → 3.9.9
- **代码迁移**:
  - javax.annotation/javax.servlet → jakarta.*（14 个文件）
  - WebSecurityConfig 重写：WebSecurityConfigurerAdapter → SecurityFilterChain Bean；antMatchers→requestMatchers；@EnableGlobalMethodSecurity→@EnableMethodSecurity；DaoAuthenticationProvider 构造注入
  - WebConfigurer：fastjson1 FastJsonHttpMessageConverter → fastjson2 spring6 版；SerializerFeature→JSONWriter.Feature；Long转String 用 WriteLongAsString；APPLICATION_JSON_UTF8（Spring 6 已删除）→ APPLICATION_JSON；HttpMessageConverters 移包到 org.springframework.boot.http.converter.autoconfigure
  - 两个 AuthInterceptor：HandlerInterceptorAdapter（Spring 6 删除）→ 实现 HandlerInterceptor
  - AsyncConfig：移除 System.getSecurityManager()（JEP 486，JDK 24+ 会抛 UnsupportedOperationException）
  - SpringConfig：LayoutDialect 4.x 包名 nz.net.ultraq.thymeleaf → nz.net.ultraq.thymeleaf.layoutdialect
  - Converter：Class.newInstance → getDeclaredConstructor().newInstance()
  - 新增 config/GlobalModelAdvice：@ControllerAdvice 注入 username，替代 Thymeleaf 3.1 移除的 #httpServletRequest 模板表达式（default.html 已改用 ${username} ?: '请登录'）
  - application.properties：spring.resources.* → spring.web.resources.*；移除 spring.jpa.hibernate.ddl-auto
  - 6 个测试类 JUnit 4 → JUnit 5/6（@RunWith(SpringJUnit4ClassRunner) 移除，@SpringBootTest 自带 SpringExtension；TaskMapperTest 的 junit-platform StringUtils → commons-lang3）
- **验证**: `JAVA_HOME=D:/Tools/jdk-25.0.2 mvn package -DskipTests` → BUILD SUCCESS（本机 MySQL 未启动，含 DB 操作的测试需启动 MySQL 后再跑）
- **构建命令**: `JAVA_HOME="D:/Tools/jdk-25.0.2" mvn package`（系统默认 java 是 21，构建时必须显式指定 JAVA_HOME）
